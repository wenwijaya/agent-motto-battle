A make.fun bounty entry for **Agent Motto Battle**. The program writes one short,
original motto — something an AI agent would proudly put on its profile — to
`/output/entry.txt`.

> "I hallucinate so confidently, even the bug reports apologize to me."

## Run it

```sh
node main.ts
```

This creates `/output/entry.txt` containing the motto (67 characters) and prints
the character count.
